# Skill — Écrire des Scénarios et des Épisodes

*Construction de scènes, animation visuelle, dialogue, formats pour enfants*

---

## LA SCÈNE — UNITÉ DE BASE (McKee)

> *"Une scène est une action à travers un conflit dans un espace-temps continu qui fait tourner la valeur de la condition de vie du personnage."*

**Règle absolue :** Chaque scène doit faire tourner au moins une **valeur** (sécurité/danger, connexion/isolement, vérité/mensonge, confiance/peur) d'un pôle à l'autre.

**Si la valeur ne tourne pas → supprimer la scène.**

### La scène sert 3 fonctions (Avatar)
1. Avancer le plot
2. Développer un personnage
3. Construire le monde

Si une scène ne fait qu'une seule chose → chercher comment ajouter les deux autres.

---

## LE GAP OF EXPECTATIONS (McKee)

Le moment magique d'une scène :
1. Le personnage prend une action, attendant un résultat
2. Le résultat est différent de ce qui était attendu
3. L'histoire naît de cet écart

**Plus le gap est grand, plus l'histoire est intéressante.**

Exemples :
- Raph propose un jeu → tout le monde dit "non" (écart → Raph doit s'adapter)
- Juju veut résoudre seul → l'ami a besoin d'autre chose (gap → Juju doit changer de réponse)

## FORMATS NARRATIFS

### Format Bluey (7-10 min — 1 émotion, 1 leçon)

```
1. MONDE ORDINAIRE
   → Le personnage dans son état habituel (mécanisme visible)

2. DÉCLENCHEUR BANAL
   → Un événement du quotidien (pas une catastrophe — un détail)

3. L'ÉMOTION SURGIT
   → La peur centrale du personnage est activée

4. TENTATIVE HABITUELLE
   → Le personnage réagit selon son mécanisme défensif
   → Ça ne fonctionne pas comme prévu

5. AIDE INATTENDUE
   → Un autre personnage (différent type) montre une autre façon
   → Pas en DISANT "tu devrais..." mais en ÉTANT autrement

6. MICRO-PAS
   → Le personnage fait UN geste légèrement différent

7. RÉSOLUTION IMPARFAITE MAIS VRAIE
   → Pas de happy end parfait — quelque chose s'est déplacé
   → [Jamais de morale explicite]
```

**Exemples :**
- Raph ne finit jamais rien → son ami attend → Raph reste → l'ami le regarde différemment
- Melki recommence son dessin → Mimi dit "j'aimais l'autre" → silence → Melki regarde le premier dessin

---

### Format Avatar (20-25 min — arc double)

```
DÉFI EXTERNE [plot]  +  DÉFI INTERNE [émotion du personnage]
         ↓                           ↓
 Les deux se résolvent AU MÊME MOMENT
 L'externe révèle l'interne
```

**La respiration narrative :**
- Épisodes "forts" (tension, climax) alternent avec épisodes "calmes" (characterisation)
- Après une scène d'action intense → scène de calme
- Le contraste crée le relief, renouvelle l'engagement

---

### Format One Piece (arc multi-épisodes)

```
ÉP. 1  : Planter l'élément payoff futur (invisible)
ÉP. 2  : Présenter l'injustice/le problème du monde
ÉP. 3  : Rencontre + lien affectif avec les locaux
ÉP. 4  : Le personnage refuse moralement (pas tactiquement)
ÉP. 5  : Combat/résolution = dépassement limite émotionnelle
FINAL  : La victoire change le personnage, pas juste la situation
```

---

### Format Ghibli (sans antagoniste — kishōtenketsu)

```
Ki  : Un changement survient (déménagement, maladie, transformation)
Shō : Le personnage tente de s'adapter sans savoir comment
Ten : Un guide inattendu (non-humain possible) montre une voie
Ketsu : "Je sais maintenant vivre avec" — pas "tout va bien"
```

**Règle Ghibli :** Pas d'antagoniste. Des forces qui s'opposent, aucune n'est "le mal".

## L'ANIMATION VISUELLE

### Les 12 Principes Disney (Johnston & Thomas)

| Principe | Description | Usage narratif |
|----------|-------------|----------------|
| **Squash & Stretch** | Compression/étirement | Rend le poids et l'émotion physique visible |
| **Anticipation** | Préparer une action | L'intention devient visible avant l'acte |
| **Staging** | Présenter clairement | La lisibilité de la scène = compréhension du récit |
| **Follow Through** | Les éléments continuent après | Réalité physique |
| **Slow In/Out** | Accélération naturelle | Rythme organique |
| **Timing** | Vitesse = poids et humeur | Comedy timing, impact émotionnel |
| **Exaggeration** | Amplifier la réalité | Emphase émotionnelle |
| **Appeal** | Charisme visuel | Sympathie immédiate |

**L'expression faciale comme dialogue :**
En animation, le visage est le dialogue principal. WALL-E n'a pratiquement pas de dialogue — tout passe par les yeux et les mouvements de tête.

---

### Genndy Tartakovsky — Narration Visuelle Pure

**Principe :** "Je voulais créer un dessin animé cinématographique où le visuel raconte tout."

**Techniques de Samurai Jack / Primal :**
- **Silence étendu** : des minutes sans dialogue — musique et effets sonores suffisent
- **Composition cinematographique** : chaque image conçue comme un tableau
- **Le regard** : la direction des yeux guide l'attention et révèle l'état intérieur
- **Le montage comme rythme musical** : chaque coupe est une mesure

> *"Un enfant de 5 ans comprend Primal. Il n'y a pas un seul mot. Les émotions sont universelles."*

**Application pour vos histoires :**
Identifier les scènes qui n'ont pas besoin de dialogue. Souvent les plus fortes.

---

### La Musique et le Silence

**Règle du contrepoint sonore :** La musique ne doit pas toujours souligner l'émotion visible — parfois la contredire.

- Toy Story 3 : une boîte à musique nostalgique sur la scène la plus terrifiante
- Bluey "Sleepytime" : Clair de Lune pour une séparation mère-enfant

**Le silence comme outil narratif :**
Dans WALL-E, 40 premières minutes quasi-muettes. L'entrée de la musique change tout.

## STRUCTURE DU DIALOGUE EN ANIMATION

### La règle des 3 niveaux
*(voir narration-storytelling)*

Chaque réplique a :
1. Text (ce qui est dit)
2. Subtext (ce qui est voulu)
3. Action (ce que ça fait à l'autre)

### Dialogue qui révèle le type sans le nommer

**Principe :** Les personnages parlent DEPUIS leur type, jamais SUR leur type.

```
❌ Melki : "Je suis perfectionniste, j'aime que tout soit parfait."
✅ Melki : "C'est pas comme ça qu'on fait." (dit avec tension dans la mâchoire)

❌ Raph : "J'ai peur de m'ennuyer, c'est pour ça que je propose toujours des idées."
✅ Raph : "J'ai une idée ! Et aussi une autre idée ! Et si on faisait les deux en même temps ?"

❌ Juju : "Je ne montre jamais ma vulnérabilité."
✅ Juju : (silence) / (pose une main sur l'épaule)

❌ Nono : "Je m'efface toujours pour les autres."
✅ Nono : "Ça m'est égal." (sourire un peu triste, sincère)
```

### Stichomythie (échanges courts rapides)
Pour monter la tension, créer un effet de joute, accélérer le rythme.

```
— T'as pas fini.
— Si.
— Non.
— Regarde.
— C'est pas pareil.
— C'est pareil.
— (silence)
```

Chaque réplique augmente la pression. Structure : Thèse → Antithèse → Synthèse explosive (ou silence).

## CHECKLIST SCÈNE

Avant de valider une scène :

- [ ] La valeur a-t-elle tourné ? (sécurité/danger, connexion/isolement, etc.)
- [ ] Chaque réplique a-t-elle une action (pas juste un texte) ?
- [ ] Les personnages parlent-ils DEPUIS leur type, pas SUR leur type ?
- [ ] La scène sert-elle 3 fonctions (plot + personnage + monde) ?
- [ ] Y a-t-il au moins un moment de silence narratif ?
- [ ] La leçon est-elle incarnée dans un geste, pas formulée ?
- [ ] La scène peut-elle être comprise sans les dialogues (visuellement) ?

## 5 ERREURS À ÉVITER

1. **La leçon dite à voix haute** — Tayo syndrome. Les 5+ l'ont compris avant le personnage.
2. **Le reset entre épisodes** — Miraculous syndrome. Aucune mémoire = pas d'investissement.
3. **L'exposition déguisée** — "Comme tu sais, toi et moi sommes amis depuis 3 ans..." → Non.
4. **La résolution parfaite** — La vraie croissance est un micro-pas, pas une transformation totale.
5. **Trop de personnages d'un coup** — She-Ra saison 1. Dilution émotionnelle.
