# Micro-craft d'exécution

## 1. Show Don't Tell (montrer plutôt que dire)

> *Tchekhov : « Ne me dis pas que la lune brille. Montre-moi le reflet sur le verre brisé. »*

| Au lieu de (tell) | Faire (show) |
|---|---|
| Dire l'émotion | Un geste du corps : « Ses mains tremblaient en saisissant le micro. » |
| Dire le trait de caractère | Une action : il se plaint qu'on a oublié son demi-anniversaire (= égoïste). |
| Décrire le décor | Le faire vivre par les sens : « Les feuilles sèches crissaient sous ses pieds. » |

**Audit par scène** : que veux-je montrer ? quelle est la façon la plus *visuelle* ? y a-t-il du dialogue « pour passer le temps » sans enjeu ?

## 2. Sous-texte (le non-dit)

Le sens sous les mots. *« Good dialogue is the art of the NOT said. » (McKee)*
- **Mots vs actions** : « Tout va bien », dit-il en enfilant son manteau pour partir au milieu de la dispute.
- **Évitement du sujet** : « Tu as lu mon message ? » — « Il fait beau aujourd'hui. »
- **Le silence** : « Tu me fais confiance ? » — Elle détourne les yeux.

*(Pour les 4-6 ans : sous-texte LÉGER seulement — la théorie de l'esprit émerge à 4-5 ans, cf. `05-developpement`. Pas d'ironie complexe avant 8 ans.)*

## 3. Scène & Séquelle (Swain) — le battement du récit

```
SCÈNE (action) :   Goal → Conflict → Disaster
SÉQUELLE (réaction) : Reaction → Dilemma → Decision → nouveau Goal
```
La **scène** = le pouls fort (on tente, on échoue). La **séquelle** = la récupération (on encaisse, on décide la suite).
- Scène longue + séquelle courte = rythme rapide. Inverse = introspection.

## 4. Beats émotionnels (micro-moments)

| Beat | Quoi | Exemple |
|------|------|---------|
| **Physique** | geste révélateur | tapoter des doigts, éviter le regard |
| **Environnemental** | interaction décor | serrer un verre, triturer un objet |
| **Relationnel** | dynamique entre persos | une pause avant de répondre |
| **Interne** | pensée intérieure | « Il sut alors que c'était fini. » |

**Règle d'or** : alterner dialogue ↔ beat pour un rythme naturel. *« Je te fais confiance », dit-il. Il vérifia que la clé était toujours dans sa poche.*

## 5. Rythme (pacing)

| | Accélérer | Ralentir |
|---|---|---|
| Phrases | courtes | longues |
| Mots | simples | descriptifs |
| Dialogue | échanges vifs | monologue |
| Action/description | action | description |

**Le contraste crée le rythme.** Après une scène intense → une scène calme (le relief). Voir aussi `16-oralite` (le rythme *entendu*).

## 6. ⚠️ Cliffhangers — OFF pour la fin

Les techniques d'accroche (peril-cut, question ouverte, effet Zeigarnik) servent **au milieu** pour tenir l'attention entre deux moments. **JAMAIS pour clore une histoire MaxPlay** : la patte = Kishōtenketsu apaisant, la fin **referme** (cf. `17-refrains` le refrain-rituel de clôture). Désactiver cette tentation au rewrite.
