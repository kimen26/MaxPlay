## 🔒 Règles MaxPlay (à appliquer en lisant n'importe quel sous-fichier)

- **Casting V1 figé** : Wex + Melki(1)/Mimi(2)/Dadou(3)/Madie(4)/Lulu(5)/Pierrot(6)/Raph(7)/Juju(8)/Nono(9). Les exemples des sous-fichiers ont été remappés depuis l'ancien casting. ⚠️ *Relecture accords de genre en cours (Melki/Raph/Juju/Nono ont changé de genre).*
- **🛑 Garde-fou anti-cliffhanger** : la patte MaxPlay = **Kishōtenketsu apaisant** (fin-image qui referme en douceur, pour écoute au coucher). Les techniques de **cliffhanger / open-loop / variable reward** (présentes dans `01-storytelling` et `07-scenario`) servent au *milieu* pour tenir l'attention — **JAMAIS pour la fin**. Ne pas « accrocher » le Ketsu.
- **Univers implicite** : jamais nommer un ennéatype/système dans le texte (le craft les dilue dans le comportement).
- **Ennéagramme = source de vérité ailleurs** : pour la théorie + les fiches incarnées, voir [`../../studio/narration/personnages/theorie/enneagramme/`](../../studio/narration/personnages/theorie/enneagramme/) (le skill `enneagramme` deprecated est superseded). Ici, seules les **tables ennéa×craft** illustrent l'application.
