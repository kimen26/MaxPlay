# _inbox — Zone de dépôt libre

> Dépôt brut multi-pôles (JEU + NARRATION + idées générales).
> Pas de format imposé. Tu balances, on trie.

## Règle dorée

- **Max 48h de vie.** Dès qu'on traite → distiller vers le bon fichier cible, puis supprimer.
- Si c'est clairement narration → copier aussi dans [`narration/INBOX.md`](../narration/INBOX.md) avec la convention de section.
- Si c'est clairement jeu → signaler à game-pmo.

## Convention de section

```
## YYYY-MM-DD — sujet libre
[contenu brut, format libre]
```

## Qu'est-ce qui va ici ?

- Idées brutes pas encore catégorisées
- Textes copiés-collés depuis une autre source
- Notes de session non structurées
- Liens, captures, références à garder temporairement
- Tout ce qui ne sait pas encore où aller
