# Archive — Sessions éditoriales

> Sessions archivées par le Directeur Éditorial après chaque cycle de travail.
> **Rien n'est effacé.** Tout peut être retrouvé.

## Convention de nommage

```
YYYY-MM-DD-<sujet>.md
```

## Ce qu'une archive contient

- Résumé de la session
- Décisions prises (avec raisons)
- Ce qui a été écarté (avec raisons)
- Pointeurs vers les fichiers mis à jour
