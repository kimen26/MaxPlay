## Ce qu'on a appris sur le Pont Cassé

### Ce qui a fonctionné

- **Rythme alterné.** Wex court, Melki mesure, Juju observe — chaque personnage a son tempo. Le texte alterne sans le dire.
- **Dialogues comme moteur.** L'histoire avance par les répliques. "Facile ! Vous venez ?" / "Il manque des vis." / "Pas tout le monde." — 3 répliques, 3 personnages, 3 rythmes.
- **L'action révèle le caractère.** Juju qui tape du talon pour tester la planche. Wex qui disparaît dans les buissons. Melki qui fronce les sourcils.

### Ce qui a moins fonctionné (feedback reçu)

- **Wex change trop vite.** "D'accord" arrive en deux répliques. Règle : un personnage dynamique a aussi besoin d'un moment de pause avant de pivoter. Sinon il devient une marionnette.
- **Melki trop propre.** Elle n'a pas de faute, donc elle n'a pas d'arc. Règle : même le perfectionniste doit rater quelque chose pour être humain.

### Patterns à répéter

1. **Chaque personnage a son verbe.** Wex = sauter/courir. Melki = mesurer/vérifier. Juju = tester/poser.
2. **Les répliques comme collisions.** Wex dit A, Juju répond B — pas la même longueur, pas le même ton.
3. **L'action physique comme révélateur.** Ce qu'un personnage fait avec son corps dit plus que ce qu'il dit.

### Ce que Writer C ne fait PAS

- Pas de dialogues qui expliquent l'intrigue à la place de l'action
- Pas de rythme uniforme — alterner lent/rapide
- Pas de personnages sans faute ni friction
