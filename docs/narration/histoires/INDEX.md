## Règles d'écriture (rappels)

- **Notation personnages : `TypeN` / `TitiN` × origine** (voir [../personnages/notation-types.md](../personnages/notation-types.md)). Origine par défaut : **Christ**. Wex reste toujours **Wex** (hors-système).
- **Univers IMPLICITE par défaut.** Les histoires enfantines se passent dans notre univers post-Éveil, **sans le dire explicitement**. Pas de nom de monde, pas de « Conscience Créative », pas de « Grand Tout » nommés. L'univers infuse par détails discrets (un reflet qui réagit, une plante qui penche, un compagnon animal présent sans commentaire). **Le lien se tisse progressivement** au fil des histoires — pas d'un coup.
- **Ennéatypes DILUÉS dans le comportement.** Jamais nommer « le Type7 », « le pacificateur » etc. Le type se lit dans les **actions, échanges, micro-réactions**, pas dans une étiquette. Un enfant qui rit trop fort et propose une cabane = Titi7 sans qu'on le dise. Le lecteur (Max ou adulte) ne doit pas voir la grille, juste sentir des personnalités vivantes.
- **Ennéagramme = grille, pas cage.** Les persos agissent selon leur type mais peuvent surprendre.
- **Kishōtenketsu privilégié** (exposition · développement · twist · résolution, **sans antagoniste**)
- **POV enfant né après l'Éveil** → rien ne l'étonne, le merveilleux est normal
- **Pas de moralisme.** On montre, on ne dit pas ce qu'il faut penser.
- **Âge cible :** 3.5–4 ans (Max). Phrases courtes, vocabulaire concret, rythme clair.
