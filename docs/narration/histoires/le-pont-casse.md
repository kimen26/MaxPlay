- Le compagnon de Juju se détasse / s'éclaircit quand la planche est posée (forme exacte à trancher — voir `univers/compagnons.md`).

**Option B — Touches moyennes**
- La planche en frêne "voulait" être posée là — Melki le ressent sans pouvoir l'expliquer.
- La petite fille qui traverse est accompagnée d'une forme (compagnon) qui gambade sur le pont le premier matin.

**Option C — Immersion complète** *(à éviter pour les premières histoires — contrevient à la règle "univers implicite")*
- Le pont cassé est dans un lieu qui "sent" les frictions non résolues.
- Juju voit une vieille peur du quartier rétrécir quand le pont est réparé.

**Recommandation :** Option A. Les touches doivent être quasi-invisibles — on les remarque à la 3e lecture, pas à la 1ère.
