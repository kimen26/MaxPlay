## 8. Règles d'écriture non-négociables

4. Pas d'étonnement des enfants devant le monde : ils sont nés dedans.
5. S'unir pour, pas contre. Un groupe qui se définit par un ennemi = signal de danger narratif interne.
6. Pas de religion nommée. Les enfants disent "leur lumière", "le Grand Tout", "l'étincelle".
