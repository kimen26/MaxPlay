# Prénoms — Basque (Euskara)

> Aire : Pays basque (sud-ouest France, nord Espagne). Langue isolée, sonorités vocaliques fortes, voyelles ouvertes.
> Particularité : prénoms souvent à **signification directe** (joie, paix, lumière, force) issus du vocabulaire basque. Très accessibles aux francophones.

---

## Argia

**Genre** : féminin
**Origine** : Basque — *argia* ("lumière")
**Signification** : "lumière"
**Sonorité** : doux · 3 syllabes (ar-gi-a) · ressenti lumineux, ample
**Usage** : poétique, ressuscité
**Ennéatypes possibles** :
- **Type 3 — Performeur** : *"lumière qui rayonne"* (sens direct)
- **Type 4 — Romantique** : *"lumière intérieure"* (lecture poétique)

**Statut** : brouillon
**Source** : session-fondatrice-2026
