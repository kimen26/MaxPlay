# Prénoms — Tibétain

> Aire : Tibet, Bhoutan, Ladakh, diaspora tibétaine. Tradition bouddhiste vajrayana, mots-concepts spirituels.
> Particularité : prénoms à **signification spirituelle directe** (compassion, félicité, diamant indestructible). Sonorités douces avec consonnes aspirées.

---

## Dechen

**Genre** : mixte
**Origine** : Tibétain — *bde chen* ("grande félicité")
**Signification** : "grande félicité, bonheur spirituel"
**Sonorité** : doux · 2 syllabes (de-chen) · ressenti élevé, lumineux
**Usage** : vivant chez les Tibétains
**Ennéatypes possibles** :
- **Type 7 — Épicurien** : *"grande félicité, joie spirituelle"* (sens direct)

**Statut** : brouillon
**Source** : session-fondatrice-2026
