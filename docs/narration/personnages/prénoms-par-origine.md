# Prénoms par origine — concept cross-country

> **Idée directrice :**
> **Wex est le héros universel hors-système** — pas d'ennéatype assigné pour le moment, jamais traduit.
> Les **9 copains typés changent selon la version linguistique/culturelle** publiée (8 actuellement, 9e à décider si Wex se voit attribuer un type plus tard).
> Les **ennéatypes, essences, comportements, relations** restent identiques d'une version à l'autre.
> → une seule structure narrative, N castings pour la publication cross-country.
> **Origine par défaut : "Christ"** (casting V1 validé).
> **Notation dans les textes** : `TypeN` ou `TitiN` croisé avec l'origine → voir [notation-types.md](notation-types.md).

---

## Principe formel

```
prénom(personnage) = f(type_ennéagramme, origine_casting)
# Wex est hors-système : pas de type, pas de traduction. Toujours "Wex".
# Origine par défaut quand non spécifiée : "Christ".
```

Chaque version partage :
- Les 9 profils ennéagram (voir `Eneagramme/personnages/type-XX-*.md`)
- Les arcs narratifs et situations (voir `Eneagramme/situations/`)
- L'univers post-Éveil, les compagnons animaux, le Cercle de Paix
- Le héros Wex (#7)

Seuls changent les 8 prénoms des copains + éventuellement quelques éléments culturels décor (repas, rituels locaux) à la discrétion de la traduction.

## Règles de cohérence cross-country

1. **Wex ne bouge jamais.** Pas de "Wex-version-japonaise". C'est une marque identifiante du héros. **Wex n'a pas d'ennéatype assigné pour le moment** — il reste hors-système.
2. **Même nombre de filles dans toutes les versions** (minimum 3 si on pousse V1 à 3F, sinon 2F partout). À décider une fois puis appliquer.
3. **Les diminutifs enfantins** doivent fonctionner à l'oral dans la langue cible. Pas de "Pierrot" en japonais.
4. **Les animaux totem** (compagnons) peuvent rester identiques ou s'adapter à la faune locale — à trancher casting par casting.
5. **Rituels universels conservés** : Cercle de Paix, Grand Tout, Conscience Créative. Le vocabulaire peut être traduit, pas remplacé par un équivalent religieux local (risque de dénaturer l'univers post-Éveil).

## Pourquoi ce concept

- **Accessibilité cross-country** à coût narratif quasi nul : 8 prénoms à swap, pas de réécriture.
- **Max lui-même** est biculturel (origines brésiliennes, passionné de drapeaux) → les versions multiculturelles ont du sens personnel.
- **Richesse pédagogique** : 9 profils humains universels, prouvés par la diversité des incarnations culturelles.
- **Industriel** : une fois l'univers figé, publier une nouvelle version = un sprint de nommage + illustration, pas un projet.
