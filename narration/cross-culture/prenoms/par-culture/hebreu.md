# Prénoms — Hébreu (biblique et moderne)

> Aire : monde hébraïque ancien et contemporain (Israël, diaspora juive). Source biblique majeure pour la culture occidentale. Beaucoup de prénoms hébreux ont des **équivalents francophones courants** (Marie, Pierre, Madeleine, Raphaël, Noé, Judith) — le casting V1 du projet est largement nourri de cette source.
> Particularité : signification spirituelle directe (lumière, paix, justice, force divine), souvent théophore (contient un nom divin).

---

## Lior

**Genre** : mixte (plus souvent masculin)
**Origine** : Hébreu moderne — *li-or* ("ma lumière")
**Signification** : "ma lumière"
**Sonorité** : doux · 2 syllabes (li-or) · finale ouverte · ressenti lumineux, intime
**Usage** : vivant en Israël, peu connu en France
**Ennéatypes possibles** :
- **Type 4 — Romantique** : *"lumière intérieure — lien direct avec 'leur lumière' de l'univers"* (sens : la lumière personnelle, profonde)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Mariam

**Genre** : féminin
**Origine** : Hébreu / araméen — racine de Marie/Myriam
**Signification** : "pure, élevée"
**Sonorité** : doux · 3 syllabes (ma-ri-am) · ressenti ample, classique
**Usage** : vivant, cross-culturel (arabe, hébreu, chrétien)
**Ennéatypes possibles** :
- **Type 1 — Perfectionniste** : *"pureté, élévation morale"* (sens direct)

**Statut** : brouillon
**Source** : session-fondatrice-2026

---

## Nathan

**Genre** : masculin
**Origine** : Hébreu — *natan* ("don de Dieu")
**Signification** : "don de Dieu" — prophète qui confronte David
**Sonorité** : ferme · 2 syllabes (na-than) · ressenti franc, droit
**Usage** : vivant, universel en Occident
**Ennéatypes possibles** :
- **Type 1 — Perfectionniste** : *"prophète qui dit la vérité au roi, justice"* (figure : Nathan le confrontant)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Miriam

**Genre** : féminin
**Origine** : Hébreu — *Miryam* (sœur de Moïse)
**Signification** : "danse au tambourin à la Mer Rouge — joie exubérante"
**Sonorité** : doux · 3 syllabes (mi-ri-am) · ressenti dansant, ample
**Usage** : vivant, cross-culturel
**Ennéatypes possibles** :
- **Type 7 — Épicurien** : *"joie exubérante, danse, célébration"* (figure biblique de joie)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Uriel

**Genre** : masculin
**Origine** : Hébreu — *Or-El* ("lumière de Dieu")
**Signification** : "lumière de Dieu" — archange (livre d'Hénoch)
**Sonorité** : doux · 3 syllabes (u-ri-el) · ressenti lumineux, élevé
**Usage** : vivant, rare
**Ennéatypes possibles** :
- **Type 4 — Romantique** : *"vision intérieure, lumière de Dieu"* (figure de visions, profondeur spirituelle)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Ézéchiel

**Genre** : masculin
**Origine** : Hébreu — *Yehezqel* ("Dieu fortifie")
**Signification** : "Dieu rend fort" — prophète des visions hallucinées
**Sonorité** : ferme · 4 syllabes (é-zé-chi-el) · ressenti puissant, original
**Usage** : vivant mais rare, marqué prophétique
**Ennéatypes possibles** :
- **Type 4 — Romantique** : *"visions hallucinées, original radical"* (figure : prophète des visions)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Note — prénoms du casting V1

Plusieurs prénoms du casting V1 figé sont d'origine hébraïque (via leur figure biblique) :
- **Melki** ← Melchisédech (#1)
- **Mimi** ← Marie (#2)
- **Madie** ← Madeleine / Marie de Magdala (#4)
- **Pierrot** ← Pierre / Kepha (#6)
- **Raph** ← Raphaël (archange) (#7)
- **Juju** ← Judith (#8)
- **Nono** ← Noé (#9)

Ces prénoms restent **réservés-V1** pour la version francophone ; ce fichier liste les variantes hébraïques utilisables pour les versions culturelles alternatives.
