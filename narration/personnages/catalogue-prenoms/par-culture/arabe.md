# Prénoms — Arabe

> Aire : monde arabophone (Maghreb, Machrek, Golfe), avec rayonnement musulman au-delà (Indonésie, Asie centrale, Afrique de l'Ouest).
> Particularité : prénoms souvent à **signification spirituelle ou morale** directe (justice, joie, compassion, lumière). Sonorités franches, racines trilittères.

---

## Adil

**Genre** : masculin (féminin sous forme Adila)
**Origine** : Arabe — racine *'adala* ("être juste")
**Signification** : "juste, équitable"
**Sonorité** : ferme · 2 syllabes (a-dil) · ressenti droit, posé
**Usage** : vivant, classique dans le monde arabophone
**Ennéatypes possibles** :
- **Type 1 — Perfectionniste** : *"justice, équité — sens littéral"* (alignement fort)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Rahma

**Genre** : féminin
**Origine** : Arabe — *raḥma* ("compassion, miséricorde", racine *raḥim* = matrice)
**Signification** : "compassion maternelle, miséricorde"
**Sonorité** : doux · 2 syllabes (rah-ma) · ressenti chaleureux, enveloppant
**Usage** : vivant, classique
**Ennéatypes possibles** :
- **Type 2 — Altruiste** : *"compassion maternelle, racine 'matrice' = don absolu"* (sens direct)

**Statut** : brouillon
**Source** : session-fondatrice-2026

---

## Farah

**Genre** : féminin (mixte)
**Origine** : Arabe — *faraḥ* ("joie")
**Signification** : "joie"
**Sonorité** : doux et ouvert · 2 syllabes (fa-rah) · finale aspirée · ressenti lumineux, joyeux
**Usage** : vivant, universel et lumineux
**Ennéatypes possibles** :
- **Type 7 — Épicurien** : *"joie — sens direct, universel"* (alignement parfait)

**Statut** : brouillon
**Source** : session-fondatrice-2026

---

## Salam

**Genre** : mixte
**Origine** : Arabe — *salām* ("paix")
**Signification** : "paix"
**Sonorité** : doux · 2 syllabes (sa-lam) · ressenti apaisé
**Usage** : vivant, salutation universelle dans le monde arabe
**Ennéatypes possibles** :
- **Type 9 — Pacificateur** : *"paix — sens direct"* (alignement fort)

**Statut** : brouillon
