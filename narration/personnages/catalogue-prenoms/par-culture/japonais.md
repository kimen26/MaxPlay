# Prénoms — Japonais

> Aire : Japon (japonais classique, kanji + kana). Très présents dans l'imaginaire de Max via Ghibli/Totoro. Forte densité de prénoms à **signification directe** (lumière, paix, courage, sagesse) via les kanji.
> Particularité : sonorités douces, syllabes ouvertes, finales en voyelle. Compatible "ton Ghibli pur" évoqué dans les règles d'écriture.

---

## Makoto

**Genre** : mixte (souvent masculin)
**Origine** : Japonais — kanji 誠 ("sincérité, vérité")
**Signification** : "authenticité, sincérité, vérité" — vertu bushido
**Sonorité** : doux · 3 syllabes (ma-ko-to) · ouvertures vocaliques régulières · ressenti calme, droit
**Usage** : vivant, classique, intemporel
**Ennéatypes possibles** :
- **Type 1 — Perfectionniste** : *"authenticité bushido, droiture morale"* (sens direct : la vérité comme idéal)

**Statut** : brouillon
**Source** : session-fondatrice-2026
