# Prénoms — Mongol

> Aire : Mongolie, Bouriatie, Kalmoukie. Tradition nomade, chamanique, bouddhiste tibétaine.
> Particularité : prénoms enracinés dans le **ciel, la nature, le héros, le métal**. Sonorités fermes, voyelles ouvertes.

---

## Naran

**Genre** : féminin (mixte)
**Origine** : Mongol — *naran* ("soleil")
**Signification** : "soleil"
**Sonorité** : doux et ferme · 2 syllabes (na-ran) · ressenti chaud, ample
**Usage** : vivant, classique
**Ennéatypes possibles** :
- **Type 3 — Performeur** : *"soleil, éclat"* (sens direct)
- **Type 7 — Épicurien** : *"chaleur solaire, joie"* (lecture joyeuse)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Enkh

**Genre** : mixte
**Origine** : Mongol — *enkh* ("paix")
**Signification** : "paix"
**Sonorité** : ferme · 1 syllabe · finale aspirée · ressenti net
**Usage** : vivant en composé (Enkhbayar, Enkhtuya)
**Ennéatypes possibles** :
- **Type 9 — Pacificateur** : *"paix — sens direct"* (alignement fort)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Altan

**Origine** : Mongol — *altan* ("or")
**Signification** : "or, doré"
**Sonorité** : ferme · 2 syllabes (al-tan) · ressenti précieux, royal
**Usage** : vivant, classique
**Ennéatypes possibles** :
- **Type 3 — Performeur** : *"or, valeur précieuse, brillance"* (sens : l'éclat doré)

**Statut** : brouillon
**Source** : session-fondatrice-2026

## Baatar

**Genre** : masculin
**Origine** : Mongol — *baatar* ("héros")
**Signification** : "héros"
**Sonorité** : ferme · 2-3 syllabes (ba-a-tar) · voyelle longue · ressenti puissant
**Usage** : vivant, élément central (Oulan-Bator = "héros rouge")
**Ennéatypes possibles** :
- **Type 8 — Chef** : *"héros — figure du fort, du protecteur"* (sens direct)

**Statut** : brouillon
**Source** : session-fondatrice-2026
