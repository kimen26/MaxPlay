## Niveaux de santé (Riso-Hudson, en arrière-plan)

Chaque type peut vivre à 9 niveaux :
- **Niveaux 1-3** : sain (libéré, épanoui, vertueux)
- **Niveaux 4-6** : ordinaire (adaptatif, mécanique, défensif)
- **Niveaux 7-9** : malsain (réactif, compulsif, pathologique)

Dans les histoires MaxPlay (cible 4-7 ans), les personnages oscillent **entre niveaux 3 et 6** selon les épisodes. Pas de niveaux 7-9 (zone clinique, hors public).
