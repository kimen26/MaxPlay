## Synthèse rapide (cheat-sheet pour brainstorm/brief)

| Capacité 4-5 ans | Implication pour l'écriture |
|------------------|------------------------------|
| Théorie de l'esprit en construction | Les persos ont des **pensées intérieures simples**, l'enfant les « voit » via gestes et phrases courtes |
| Attention conjointe | Les histoires marchent quand un **objet/lieu commun** rassemble les persos (focus partagé) |
| Jeu symbolique | Les **gestes mimables** (poser la main, fredonner, se baisser) sont des entrées d'identification |
| Miniatures et recoins (Bachelard) | Les **petits espaces** (sous l'arbre, dans la cabane, au creux du talus) captivent plus que les grands paysages |
| Causalité immédiate | Une action → une réaction. Pas de cause à effet retardé ou conditionnel |
| Mémoire de travail limitée | **Max 3 informations** à tenir en parallèle dans une scène |
| Sensorialité dominante | **Textures, sons, lumières** comptent plus que les concepts |

## Variance cross-culture

**Aucune.** Ces invariants sont cognitifs (cerveau humain 4-5 ans) — ils valent pour Max français, Max brésilien, Max japonais. Pas de fiche par culture.

Les **manifestations** des invariants peuvent varier (ce qu'un enfant français trouve « cabane recoin » diffère d'un enfant inuit), mais c'est traité dans [`cross-culture/lieux-locaux/`](../../../cross-culture/lieux-locaux/INDEX.md) — pas ici.
