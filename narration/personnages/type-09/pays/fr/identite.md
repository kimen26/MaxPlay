# Nono (Noé) — Type 9, casting France

## Origine du prénom
Noé : pacificateur du déluge, celui qui préserve l'harmonie de toutes choses.
Diminutif "Nono" doux, rond, calme — la sonorité incarne le personnage.

## Usage
- Diminutif 4/5 du temps : **Nono**
- Prénom complet pour les moments solennels : Noé
