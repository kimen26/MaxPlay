# Ennéatypes & Narration — Livres Audio Enfants 4-8 ans

## Concept

Chaque **personnage** = un **ennéatype** avec une palette vocale unique (4 tags UNIQUES + 3 partagés).
Le **narrateur** = 26 tags pour moduler le hors-dialoge.
