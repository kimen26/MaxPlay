## Points clés = STORY-002 spécifiques

Les briefs incarnent ces 5 points clés :

1. **Polo n'échoue pas — il découvre.** (Transformation, pas défaite)
2. **Nono n'enseigne pas — il existe.** (Présence active, pas absence)
3. **Libellule reste libre.** (Aucun pouvoir, aucune magie, juste elle-même)
4. **Bourdonnement = clé sensorielle du Ten.** (Pivot de l'histoire)
5. **Silence du Ketsu.** (Pas d'épilogue italique, pas de morale dite)

Chaque point est expliqué dans `brief-histoire.md` section « Bonnes pratiques STORY-002 ».
