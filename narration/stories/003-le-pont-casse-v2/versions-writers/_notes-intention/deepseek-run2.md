Ce run pousse la température narrative : structure en éclats (phrases courtes, répétitions, onomatopées), point de vue qui flotte d'un enfant à l'autre sans transition, dialogue syncopé. Le trou devient personnage (il bâille, il veut garder Raph). La chute resserre tout sur un moment immobile — pas de solution, pas de morale, juste un regard partagé. Plus risqué que la version stable : moins de linéarité, plus de poésie physique.
