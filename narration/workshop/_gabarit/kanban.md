## Étapes

- [ ] **Brainstorm Pitch** (Conseiller) → Validé par auteur
- [ ] **Plan d'Histoire** (Architecte) → Cohérent avec carte narrative
- [ ] **4 Writers** (Directeur) → Versions A/B/C/D livrées (400-700 mots + notes d'intention)
- [ ] **Lecteurs Témoins** (Directeur) → 4 réactions collectées (texte libre)
- [ ] **Sélection** (Directeur + Auteur) → Decision.md validée par auteur ⏳
- [ ] **Rewrite** (Directeur) → Rewrite.md livré
- [ ] **GateKeeper** (GateKeeper) → Verdict PASS ou corrections appliquées
- [ ] **Version Finale** (PMO) → Texte dans stories/ + index régénérés ⏳
