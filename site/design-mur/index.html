Le Mur — 3 patterns (POC)

Commun aux 3 : avatars cartoon · zone Tritri en visuel direct · parade horizontale · swipe → pour entrer dans un repaire. Ce qui change : l'encyclopédie.

POC A « La parade » L'encyclopédie est la DERNIÈRE CARTE de la parade : une carte-livre dorée avec le Roi T-Rex, visuellement distincte des copains. Les jeux dino restent chez le T-Rex… non — dans A, T-Rex n'a PAS de repaire : la carte-livre remplace son repaire. Les jeux dino devront être recasés (Découverte ou autre copain). + simple, une seule liste · − les jeux dino perdent leur copain POC B « Rex le savant » Le Roi T-Rex devient un GRAND PORTAIL doré en bas de page (trône) : il EST l'encyclopédie. Ses jeux dino passent à un nouveau copain, Anky, dans la parade. + encyclo très visible, jeux dino conservés · − introduit un 6e personnage POC C « Le livre magique » L'encyclopédie est un LIVRE DORÉ FLOTTANT, toujours visible en bas à droite (dock), sur toutes les pages du menu. Le Roi T-Rex garde son repaire de jeux dino dans la parade. + rien ne change pour les copains, encyclo accessible partout · − un élément flottant permanent peut gêner
