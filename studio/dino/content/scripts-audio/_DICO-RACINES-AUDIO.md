## NOTE DE PRODUCTION — règle des terminaisons multiples

Quand une racine a plusieurs formes orthographiques réelles dans les noms de dinos,
le clip DOIT dire les deux formes et préciser qu'elles sont identiques.
L'enfant s'énerve quand il ne reconnaît pas la terminaison — c'est la règle pédagogique centrale.

Modèle oral : « *saure* ou *sau-rus*, en grec, ça veut dire lézard — c'est pareil ! »

Racines concernées (au minimum) :
- `-saure` → formes : -saure, -saurus, -saura, -sauro-
- `-odon` → formes : -odon, -odonto-
- `-lophe` → formes : -lophus, -lopho-
- `-céphale` → formes : -céphale, -céphalo-
- `-onyx` → formes : -onyx, -nychus
- `-mime` → formes : -mimus

## SIGNAUX A VERIFIER SUR GROKIPEDIA (avant génération)

1. **`troo- / titrosko`** (Troodon) : la racine "blesser" (titrosko) pour Troodon est discutée dans la littérature spécialisée. Certaines sources donnent "blessant" (sens de la dent qui incise), d'autres rattachent *troo-* directement à *titrosko* (blesser). A confirmer sur Grokipedia avant de valider le clip `dico-troo`.

2. **`gorgo-`** (Gorgosaurus) : le sens "féroce, terrible" est standard mais *gorgos* en grec classique signifie d'abord "terrible/effrayant" (référence aux Gorgones). La formulation orale "féroce comme une Gorgone de la mythologie grecque" est pédagogiquement bonne mais vérifier que *gorgos* qualifie bien le dino et pas seulement la créature mythique nommée Gorgone.

3. **`-physis`** (Coelophysis) : le sens "forme, nature" est correct (*phusis*), mais dans le contexte de Coelophysis, la signification du nom est "de forme creuse" (les os creux). Vérifier si le nom complet signifie "à la forme creuse" ou "nature creuse" — nuance pédagogique à trancher.

4. **`Amargasaurus`** : le JSON note `a_corriger` avec la mention que le clip oublie le sens de *-saurus* = lézard. Bien inclus dans le clip `dico-amarga` (le clip des noms propres dit juste le lieu — normal pour un nom propre) ; mais la FICHE dino elle-même doit corriger selon la note du JSON.

5. **`iguano-`** : le JSON dit « *iguana* vient de l'espagnol (du taïno *iwana*) ». Le clip dit "des Caraïbes, pas du grec" — véridique, mais la formulation exacte du peuple Taïno mérite confirmation. Pas de risque pour le clip 4 ans (niveau approprié), mais noter pour les adultes.
