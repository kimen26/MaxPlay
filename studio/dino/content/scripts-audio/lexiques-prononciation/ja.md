# 恐竜名の発音辞書 — Lexique de prononciation dino (日本語 / Japonais)

> **Langue** : japonais (日本語). **Voix TTS cible** : Native Japanese (ElevenLabs `eleven_v3`).
> **Méthode** : écriture NATIVE **katakana** (カタカナ) — c'est la forme LUE par la voix — + colonne **romaji** (romanisation Hepburn) pour contrôle humain.
> **Sert à l'audio TTS voix native. Le texte parlé n'est JAMAIS affiché à l'écran** — on écrit la forme qui SONNE juste en japonais, jamais le nom latin brut (une voix japonaise lirait le latin de travers).

En japonais, les noms de dinosaures sont **transcrits systématiquement en katakana** (l'alphabet réservé aux mots étrangers). Ces formes sont largement **standardisées** dans les encyclopédies, les musées (国立科学博物館) et Wikipedia JP. On donne donc directement la graphie établie plutôt qu'un « respelling » comme en français.

---

## 1. Règles de conversion (racines grec/latin → katakana)

Le japonais n'a pas de sons isolés (sauf ん/ン = *n*) : chaque consonne traîne une voyelle. La transcription suit la **prononciation**, pas l'orthographe latine.

| Graphie savante | Son | Katakana | Exemple |
|-----------------|-----|----------|---------|
| `-saurus` | *sau-ru-su* | **サウルス** (saurusu) | Tyranno**サウルス** |
| `ch` (grec, = k) | *k* | カ/キ/ク/ケ/コ | Bra**キ**オ (Brachio) |
| `ph` | *f* → transcrit *fu/ha* | フ / rangée ハ | Dilo**フォ** (Dilopho) |
| `th` | *t* | タ/ティ/ト | Ich**チ**オ ou **ティ** |
| `y` (grec, = i) | *i* | イ / kana en -i | Pach**ィ**/Pak**i** |
| `x` | *ks* | クス / クソ | Baryon**ィクス** |
| `ae` / `oe` | *é* → *e/ai* | エ / rangée -e | Arch**ェ**opteryx |
| `c` (dur, devant a/o/u) | *k* | カ/コ/ク | **カ**rnoタウルス |
| `c` (devant e/i) | *s* | セ/シ | **セ**ratops (rare) |
| `v` | *b* le plus souvent, ou *v*=ヴ | バ/ヴァ | **ヴェ**loci / **ベ**loci |
| `r` / `l` | même son japonais | rangée ラ (ra-ri-ru-re-ro) | — |
| `ti` (latin) | *ti* | ティ | Ti**タ**nis |
| `qu` | *ku* | ク | **ケ**tzal |
| consonne finale seule | + *u* (ou *o* après t/d) | ス/ト/ド… | -don → **ドン** |

**Points clés japonais** :
- Le `-saurus` gréco-latin donne **-サウルス** (*-saurusu*), pas *-saure*. C'est LE suffixe reconnaissable.
- Pas de son *v* natif : historiquement **バ/ビ/ブ/ベ/ボ** (b), mais les formes modernes acceptent **ヴァ/ヴィ/ヴ/ヴェ/ヴォ** (v). On privilégie la forme la plus courante par dino.
- Le `L` et le `R` fusionnent (rangée ラ行) — aucune distinction.
- Voyelles longues notées **ー** (allongement) quand la forme établie l'a (ex : プテラノ**ドン** court, mais certaines finales longues).

## 3. Note — pas de « liste se lisent bien tels quels »

Cette section (§4 du gabarit FR) **ne s'applique pas au japonais** : le japonais n'utilise pas l'alphabet latin, donc **chaque nom DOIT être transcrit en katakana** pour être lu par une voix native. Il n'existe aucun nom « lu tel quel ». La table §2 est exhaustive et obligatoire.

**Suffixes récurrents (mémo)** :
- `-saurus` → **サウルス** (saurusu)
- `-raptor` → **ラプトル** (raputoru)
- `-ceratops` → **ケラトプス** (keratopusu)
- `-don` → **ドン** (don)
- `-mimus` → **ミムス** (mimusu)
- `-therium` / `-ium` → **テリウム / リウム**
- `-titan` → **ティタン**

## 4. ⚠️ Incertitudes (à faire valider par un natif / paléo-fan japonais)

Formes proposées comme la **translittération la plus standard** ; à confirmer, jamais inventées à l'aveugle.

1. **aenocyon** → アエノキオン (Aenokion). Genre récemment ressuscité (loup préhistorique *dire wolf*). Forme japonaise **peu fixée** ; on voit aussi le nom vernaculaire **ダイアウルフ** (« dire wolf ») dans la culture pop. Vérifier laquelle l'app veut prononcer (nom scientifique vs surnom).
2. **ceratosaurus / centrosaurus / ceratops** : le `c` grec devant *e/i* est ambigu. Convention établie musées = **ケ (k)** pour Cerato-/Kerato- (ケラトサウルス, ケラトプス) MAIS **セ (s)** pour Centro- (セントロサウルス). Cette asymétrie est correcte en japonais établi, mais mérite un contrôle visuel (piège pour non-natif).
3. **euoplocephalus** → エウオプロケファルス. Le `ph` de -cephalus est rendu **ケファ** (ke-fa) dans les formes savantes japonaises, PAS ケハ. Chaîne longue et rare ; confirmer la coupe des kana.
4. **ichthyosaurus** → イクチオサウルス. Le cluster `chth` est difficile ; forme établie = **イクチオ** (i-ku-chi-o). Une variante **イクティオ** existe. À valider.
5. **mammuthus** → **マンモス** (Manmosu). ATTENTION : la forme japonaise établie est le mot vernaculaire « mammouth » (マンモス), PAS une translittération latine « マンムトゥス ». Confirmer que l'app veut bien « マンモス » (recommandé, c'est ce qu'un enfant japonais entend) et non le latin savant.
6. **oviraptor / velociraptor** : le `v` initial → soit **ヴ** (v, moderne : ヴェロキラプトル, オヴィラプトル) soit **ビ/オビ** (b, ancien). ヴェロキラプトル est aujourd'hui dominant ; オヴィラプトル vs オビラプトル moins tranché. Choisir une convention et s'y tenir.
7. **paraceratherium** → パラケラテリウム. Grand mammifère ; forme savante avec ケ (k) et テリウム. Nom long peu courant dans la pop culture enfantine JP — confirmer.
8. **quetzalcoatlus** → ケツァルコアトルス. Racine aztèque translittérée ; forme musées JP = ケツァルコアトルス (avec ツァ = *tsa*). Confirmer la graphie exacte de ツァ vs サ.
9. **titanis** → ティタニス. Oiseau-terreur (*terror bird*), genre peu médiatisé au Japon ; forme peu fixée. Ne pas confondre avec le préfixe パタゴティタン (Patago-*titan*, dino géant) qui lui est bien établi.
10. **patagotitan** → パタゴティタン. Décrit en 2017, forme japonaise récente mais cohérente (-ティタン). Raisonnablement sûre, signalée par prudence (récence).
11. **carcharodontosaurus** → カルカロドントサウルス. Nom très long ; la coupe カルカロ (Carcharo, ch→k) est standard mais vérifier qu'aucune contraction locale n'est préférée.
12. **coelodonta / edmontonia** : genres moins « stars ». コエロドンタ et エドモントニア sont des translittérations régulières mais moins attestées dans les sources grand public JP — contrôle recommandé.

> **Sûrs (formes ultra-établies, aucun doute)** : ティラノサウルス, トリケラトプス, ブラキオサウルス, ステゴサウルス, スピノサウルス, ヴェロキラプトル, プテラノドン, アンキロサウルス, ディプロドクス, ギガノトサウルス, パラサウロロフス, パキケファロサウルス, モササウルス, スミロドン, マンモス.
