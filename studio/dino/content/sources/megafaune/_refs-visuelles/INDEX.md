# Mégafaune Cénozoïque — références visuelles (source)

> 📚 **Source documentée** (pas de l'inbox brut). Références visuelles domaine public de la mégafaune d'après-dinos (Paléogène / Néogène / Pléistocène). Rangées ici le 2026-07-03 depuis `content/inbox/` lors du lancement du chantier **famille Mammifères + Oiseaux**.
> ⚠️ **Non déployées.** Ces images (photos, gravures XIXe de Heinrich Harder / Charles R. Knight, modèles de musée) servent de **référence factuelle et visuelle** pour briefer la génération paléoart maison — elles ne vont PAS dans `site/img/dinos/` (style incohérent avec la charte, certaines sont des squelettes). Les images finales sont régénérées en paléoart maison (skill `dino-paleoart`), échelle enfant chiffrée (L-D15).

- [`megafaune_cenozoique.html`](megafaune_cenozoique.html) — recueil illustré **fact-checké** : 28 figures, 3 ères, taille/poids/époque/écologie + sources domaine public (Wikimedia / Picryl / Knight / Harder / NPS). **C'est la base factuelle** du chantier fiches.
