# Méthode de Direction Audio — Essence du Voyage Dino (Intro V5)

> Extrait de la production `recit-intro.mp3` (V5, 2026-06-17). Ce qui marche, pourquoi, et comment reproduire.

---

## 1. L'architecture émotionnelle (le squelette)

Le dialogue ne raconte pas juste des faits — il **vit une émotion ensemble**. Le schéma est :

| Phase | Rôle | Émotion | Tag |
|-------|------|---------|-----|
| **Accroche** | Narratrice pose le cadre | Joie + invitation | `[happily][excited]` |
| **Curiosité** | WEX demande | Question candide | `[curious]` |
| **Révélation** | Narratrice répond | Surprise, amusement | `[chuckles]`, `[playful]` |
| **Gravité** | Narratrice plonge dans le sujet | Sérieux, contemplation | `[serious]`, `[matter-of-fact]` |
| **Émerveillement** | WEX réagit | Étonnement | `[gasps]` (physiologique) |
| **Accélération** | Narratrice enchaîne | Excitation, rapidité | `[excited][quickly]` |
| **Pause** | Narratrice respire | Suspense, anticipation | `[pauses]`, `[gasps]` |
| **Interaction** | WEX questionne | Curiosité active | `[curious]` |
| **Confirmation** | Narratrice valide | Joie, encouragement | `[happily]`, `[playful]` |
| **Fermeture** | Narratrice invite | Complicité, jeu | `[chuckles]`, `[happily]` |

**Règle d'or** : Chaque réplique de WEX est une **réaction émotionnelle** à ce que vient de dire la Narratrice. Pas de question neutre. WEX est le **miroir vivant** de l'enfant qui écoute.

---

## 2. Les 3 types de tags (et quand les utiliser)

### A. Tags d'émotion (le cœur)
- `[happily]` — Joie continue, sourire audible. Usage : invitation, encouragement, conclusion.
- `[excited]` — Énergie haute, voix qui saute. Usage : révélation, accélération, climax.
- `[curious]` — Question, exploration. Usage : WEX pose une question, Narratrice réagit à une surprise.
- `[serious]` — Gravité, ton posé. Usage : faits importants, moments de vérité.
- `[playful]` — Joueur, espiègle. Usage : réponse légère, complicité.

### B. Tags de réaction physique (le corps)
- `[gasps]` — Surprise, souffle aspiré. **Le plus puissant pour l'émerveillement enfantin.**
- `[chuckles]` — Gloussement discret, complicité.
- `[laughs]` — Rire franc, joie ouverte.
- `[sighs]` — Soupir, soulagement, mélancolie.

### C. Tags de rythme (le tempo)
- `[quickly]` — Rapide, enchaînement dense. Usage : listes, moments d'excitation.
- `[softly]` — Doux, intime. Usage : confidence, moment précieux.
- `[pauses]` — Pause franche. **Se place AVANT la phrase qu'on veut faire respirer.**
- `[shouts]` — Cri, alarme, onomatopée joyeuse.
- `[matter-of-fact]` — Factuel, neutre. Usage : information brute, contraste avec l'émotion.

---

## 3. La règle des 2 tags (max 2 collés au début)

**Jamais plus de 2 tags collés au début d'une phrase.**

✅ Bon : `[happily][excited] Prêt à remonter le temps ?`
✅ Bon : `[curious] Et y avait [gasps] des carnivores ??!`
❌ Mauvais : `[happily][excited][playful] Prêt à remonter le temps ?`

On peut en répartir plusieurs dans la phrase, mais max 2 au début.

---

## 4. Le rythme narratif : le "respirateur"

Le dialogue respire grâce à **3 types de phrases** qui s'alternent :

| Type | Longueur | Tag | Exemple |
|------|----------|-----|---------|
| **Punch** | 2-5 mots | `[gasps]`, `[shouts]` | "Rien !" / "KA-BOOM !" |
| **Courte** | 5-10 mots | `[happily]`, `[playful]` | "Oui ! À peu près au même moment !" |
| **Longue** | 10-20 mots | `[matter-of-fact]`, `[excited]` | "Des mousses toutes simples, puis des fougères." |

**Règle** : Jamais 2 phrases longues à la suite. Toujours une phrase courte ou un punch entre deux longues.

---

## 5. L'interaction Narratrice/WEX : le "ping-pong émotionnel"

Chaque échange suit ce schéma :

```
NARRATRICE [émotion A] : Fait + émotion
WEX [émotion B] : Réaction (question, exclamation, surprise)
NARRATRICE [émotion C] : Réponse + nouvelle émotion
```

Exemple (Intro V5, ligne 17-19) :
```
NARRATRICE [serious] : Pas d'animaux. Pas de plantes. [pauses] Rien !
WEX [curious] : ah [gasp] incroyable...
NARRATRICE [curious][pauses] : Puis, dans l'eau, [softly] une MInuscule...
```

**La Narratrice ne répond pas neutrement.** Elle répond avec une émotion qui **récompense** la curiosité de WEX.

---

## 6. Les anti-patterns (ce qui casse la magie)

| Anti-pattern | Pourquoi ça casse | Correction |
|--------------|-------------------|------------|
| **Tag en anglais mal orthographié** | `[naratif]` → ElevenLabs ignore | Toujours vérifier le catalogue (`02-tags-catalog.md`) |
| **Trop de tags** | >2 au début = voix instable | Max 2 collés, répartir dans la phrase |
| **Phrase longue sans tag** | Plat, monotone | Couper en 2 phrases courtes avec tag |
| **WEX sans émotion** | Robotique, pas d'enfant | WEX a TOUJOURS une émotion (curiosité, excitation, surprise) |
| **Narratrice sans variation** | Monologue ennuyeux | Alterner `[serious]` → `[excited]` → `[softly]` → `[playful]` |
| **Réponse neutre** | "Oui, c'est ça." = plat | "Oui ! [happily] À peu près au même moment !" = vivant |
| **Coda personnel** | "un petit humain écoute" = 4e mur | Garder la magie : "la vie est une aventure immense" |

---

## 7. Checklist avant génération audio

```
□ Chaque réplique de WEX a un tag émotionnel
□ Chaque réplique de Narratrice a au moins 1 tag
□ Max 2 tags collés au début de phrase
□ Alternance : punch / courte / longue / punch
□ Pas de phrase >20 mots sans tag
□ Aucun tag hors catalogue (vérifier 02-tags-catalog.md)
□ WEX = miroir de l'enfant (curieux, excité, surpris)
□ Narratrice = guide joyeuse (jamais neutre, jamais professorale)
□ Transitions fluides (pas "On continue ? Le [Nom]" mais "On continue ! [playful] Le temps passe...")
□ Loudnorm en post-prod (jamais -c copy)
```

## 8. Exemples types à reproduire

### Accroche joyeuse
```
**NARRATRICE** [happily][excited] : Prêt à remonter le temps, Wex ? [conversational tone] On va commencer par le commencement...
```

### Révélation avec pause
```
**NARRATRICE** [serious] : Pas d'animaux. Pas de plantes. [pauses] Rien !
```

### Accélération + émerveillement
```
**NARRATRICE** [excited][quickly] : Des algues, [gasps] des petits poissons, [gasps] puis des vers...
```

### Interaction complicité
```
**WEX** [curious] : Et les plantes ? Elles "sortent" aussi de l'eau ?
**NARRATRICE** [happily] : Oui, à peu près au même moment ! [matter-of-fact] Des mousses toutes simples...
```

### Fermeture invitation
```
**NARRATRICE** [happily] : Après, on avance dans le temps. [excited] Des millions d'années se passent. [gasps] Et puis… [chuckles] Tu veux savoir la suite ?
```
