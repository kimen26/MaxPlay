## Méca (rappel)
Problème de places/passagers → choisir le bon nombre parmi 4. **8 questions**.

## Contrat de difficulté 🔒
- 🔒 **5 paliers**. Niveau = `Stars.get('mj-05') + 1`. Charger `catalog.js` + `stars.js`.
- 🔒 Axe = **type d'opération** (de plus en plus riche) :

  | Niveau | Opérations | Nombres |
  |--------|-----------|---------|
  | N1 | places libres seules | total 6-10 |
  | N2 | + monter | ≤ 12 |
  | N3 | + descendre | ≤ 15 |
  | N4 | monter/descendre/**combo** | ≤ 18 |
  | N5 | surtout **combos** | ≤ 30 |

- 🔒 **N1 = places libres uniquement** (soustraction simple, point d'entrée).
- 🔒 **Manche mixte** = 8 questions : 4 au palier courant + 4 plus faciles (mélangées). N1 → 8 faciles.
- 🔒 Étoile = **8/8 sans révélation** (`endSession(correctCount, 8)` → dérivation `correct>=questions`). maxStars = 5. `data-perfect="1"` sur l'écran de fin.
- 🔒 Sur erreur : **retry** (QcmRetry) + **indice de méthode** affiché (`#hintline`), **jamais la réponse**. Révélation après 3 essais = pas d'étoile.

## Technique 🔒
- 🔒 **Pas de variable `locked` non déclarée** (ancien bug : bloquait après Q1). `locked` déclaré + remis à `false` à chaque question.
- 🔒 Bandeau **« Niveau X »** (`#levelbar`) + rappel niveau dans le compteur de question.
