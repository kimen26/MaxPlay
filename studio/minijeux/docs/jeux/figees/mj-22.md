# MJ-22 — Trouve le pays ! · DÉCISIONS FIGÉES

> Garant écriture : game-pmo. Garant vérif : game-mj-reviewer (Section 0).

## Objectif

Trouver des pays européens sur une carte SVG propre. Apprentissage : géographie, vocabulaire prénoms pays, reconnaissance visuelle. Niveau 3.5-4 ans : Duolingo-style progression (facile → moyen → difficile).

---

## 🔒 Mécanique FIGÉE

- **Cible annoncée** : "Trouve la [Pays] !" en TTS + affichage drapeau emoji 72px
- **Interaction** : clic/tap sur un pays (rect SVG) → highlight orange (#ff8c00) + pulse animation 500ms
- **Bouton confirm** : "✓ C'est ça !" apparaît seulement APRÈS un pays sélectionné
- **Victoire juste** : overlay 2.5s fixe avec drapeau énorme (140px, animation bounce) + TTS "Bravo c'est la [Pays] !" + avance au pays suivant
- **Erreur douce** : TTS "Non ce n'est pas ça. Cherche bien." + désélection du pays (NO bounce punitif, NO son négatif fort)
- **Fin de partie** : après dernier pays trouvé → overlay final "Bravo ! Tu as trouvé tous les pays !" (défigé « Max » 2026-07-19, règle jamais-Max-dans-le-produit) + bouton Retour

---

## 🔒 Layout FIGÉ

- **Drapeau cible** : 72px, centré, sous la consigne (zone tap non-interactive)
- **Carte SVG Europe** : 100% width, aspect-ratio 1.4 (paysage), formes géographiques réelles approximées (continentale + Islande + Chypre)
- **Pays** : polygones SVG avec formes réelles reconnaissables, attribut `data-country="NomPays"` obligatoire
- **Highlight** : classe `.highlight` appliquée au clic, couleur #ff9500 + pulse animation
- **Bouton confirm** : ID `#confirmBtn`, caché par défaut, affiché seulement après sélection (classe `.show`)
- **Progress dots** : classe `.progress-dot`, circulaires 10px, fond rgba par défaut, #4CAF50 si complété (classe `.done`)
- **Victoire overlay** : classe `.victoire-overlay`, drapeau `.drapeau-victoire` 140px, durée fixe 2.5s
- **Header** : 40px bouton back (simplifié, pas de bus SVG) + emoji + "Trouve le pays !"
- **Footer** : level-info flex avec progress dots + "Facile/Moyen/Difficile"

## 🔒 TTS FIGÉ

- **Langue** : fr-FR
- **Rate** : 0.9 (légèrement ralenti pour Max)
- **Pitch** : 1.2 (tonalité légèrement plus aiguë)
- **Annonce démarrage** : "Trouve [article] [Pays] !"
  - article = "la" (défaut) | "le" (Royaume-Uni) | "l'" (Autriche)
- **Victoire** : "Bravo ! C'est la [Pays] !"
- **Erreur** : "Non ce n'est pas ça. Cherche bien."
- **Fin** : "Bravo ! Tu as trouvé tous les pays !" (défigé « Max » 2026-07-19)

---

## 🔒 Zones tap FIGÉES

- **Min 60px pour pays** : tous les `countryShapes{}` doivent avoir w ≥ 60 et h ≥ 60 pixels. Micro-pays rejetés.
- **Bouton confirm** : 120×60px (padding 12px 28px)
- **Bouton back** : 40×40px (héritée du header standard MJ)
- **Progress dots** : 12px diamètre, gap 6px

---

## 🔒 Anti-régressions — NE JAMAIS FAIRE

- ❌ 🔒 **Ajouter des micro-pays** (Malte, Luxembourg, Andorre, Monaco, Liechtenstein, Saint-Marin, Vatican) — violation zone tap 60px
- ❌ 🔒 **Afficher un score ou compteur** (cf. rules.md zéro score < 6 ans)
- ❌ 🔒 **Pénalité punitive** : pas de "perdu", pas de son négatif fort, pas de vibration punitif
- ❌ 🔒 **Session > 8 min** : Max décroche après 25 pays (difficile) ≈ 7-8 min à rythme normal
- ❌ 🔒 **Revenir à des rectangles** : la carte DOIT montrer les formes réelles des pays (Europe continentale + Islande + Chypre)
- ❌ 🔒 **Drapeau cible < 72px** : réduire sous cette taille = risque reconnaissance visuelle pauvre
- ❌ 🔒 **Victoire overlay < 2.5s** : durée min pour que Max voie + digère le succès

## 🔒 Chargement carte SVG (ajouté 2026-07-28)

- 🔒 Le loader DOIT accepter `path[id]` **ET** `g[id]` avec `cloneNode(true)`.
  Le SVG Wikimedia code le **Royaume-Uni comme un `<g id="gb">`** (Grande-Bretagne + Irlande du Nord),
  pas comme un `<path>`. Un loader qui ne lit que les `path` fait disparaître le UK de la carte
  alors qu'il reste demandé au niveau **facile** → question injouable.
- ❌ 🔒 Ne jamais revenir à `querySelectorAll('path')` seul, ni à `cloneNode()` sans `true`
  (le clone superficiel d'un `<g>` donne un groupe vide = pays invisible).
- Contrôle : 30 éléments `[data-iso]` en niveau difficile, dont `gb`.
