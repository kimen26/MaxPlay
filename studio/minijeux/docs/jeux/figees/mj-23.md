- 🔒 **5 paliers** = longueur du mot + graphèmes où la lettre ne se prononce pas seule. Niveau = `Stars.get('mj-23') + 1`.

  | Niveau | Difficulté | Exemples |
  |--------|-----------|----------|
  | N1 | court, régulier (1 lettre = 1 son) | CHAT · LUNE · VÉLO · OURS |
  | N2 | un peu plus long, régulier | POMME · BANANE · TORTUE |
  | N3 | digrammes **OU / ON** | LOUP · HIBOU · MOUTON · CITRON |
  | N4 | **AI / OI / EI / nasales** | LAIT · ROI · ÉTOILE · MAISON |
  | N5 | **EAU / AU** + mots longs | BATEAU · GÂTEAU · ESCARGOT · DINOSAURE |
