# mj-35 — Le jeu des graines — décisions figées

> Rétro-documentée 2026-09-12 (jeu vivant sans figée, écrite depuis le code réel `site/mj-35.html`).
> Garant : `game-pmo`.

- 🔒 **Mécanique mancala solo/coopérative** : des trous contiennent des graines (œufs de dino) ; semer sème une graine par trou voisin ; « PILE ! » = la dernière graine tombe pile dans le grenier.
- 🔒 **3 PILE fixes par palier**, indépendant du barème questions Golden 4/6/8 (`PILE_TARGET = 3`).
- 🔒 **Un seul trou « pile-able » par tableau** : son nombre de graines est calculé pour égaler exactement la distance au grenier ; les autres trous (leurres) ont un nombre de graines différent, borné par `decoyMax` du palier.
- 🔒 **3 paliers golden** : N1 (`pileMin:1, pileMax:3, decoyMax:4`) · N2 (`pileMin:3, pileMax:6, decoyMax:7`) · N3 « gros tas » (`pileMin:4, pileMax:6, decoyMax:12`, trous voisins à 8-12 graines pour un comptage plus dur).
- 🔒 Zéro pénalité : erreur = recompte guidé (« Je me trompe ? Pas grave, je recompte »), jamais la réponse donnée d'office.
- 🔒 Trou vide = tap silencieux (pas de son négatif), rien à semer.

## Zone ouverte (non figée — discutable librement)

- Nombre de tableaux enchaînés avant fin de manche.
