# mj-52 — La boîte à mots (Galli G3) — décisions figées

> Créé 2026-07-20 à la livraison vague 2 (spec menu v0.6 §4 G3 + délégation LLM §4).
> Garant : `game-pmo`. Source : Montessori « encoder précède décoder » (validé CNESCO 2016), POC-11/POC-12.

- 🔒 **Écrire avant de lire** : la voix DIT le mot, l'enfant l'assemble avec des lettres mobiles cursives (Cursif). Jamais l'inverse à ce niveau.
- 🔒 **Guide syllabique intégré** : le mot est découpé en cartes-syllabes (pa | pa), une case par lettre, la case suivante brille (POC-11, le syllabeur devient le guide).
- 🔒 **Paliers golden 3 niveaux** : N0 papa/maman/dodo… avec QUE les lettres du mot · N1 + mots CV/CVC (bus, sac, ami, domino) · N2 + 3 lettres distracteurs.
- 🔒 **Sur pose juste : le SON de la lettre** (jamais le nom) · mot complet relu à la fin (« Tu as écrit papa ! »).
- 🔒 **Aide après 3 erreurs : la bonne tuile s'illumine** — le jeu ne pose JAMAIS la lettre à la place de l'enfant.
- 🔒 Pas d'accents ni de graphèmes complexes dans la banque (ils arrivent avec G4 sons collés).
- ⚠ Écart spec assumé : « mot libre » (3★, son prénom) différé — demande une UI de saisie parent.
- Absorbe : POC-12 · POC-11.
