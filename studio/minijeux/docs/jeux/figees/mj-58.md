# mj-58 — Dino Run — décisions figées

> Créé 2026-07-31 à la livraison V1 (spec pack DinoJeux `2026-07-31-dinojeux-pack-logique.md` § mj-58).
> Garant : `game-pmo`.

- 🔒 **Vue LATÉRALE, rendu canvas 2D emoji** (🦖🌵🦅🥚) — pas de sprites, pas de div CSS costumées en obstacles.
- 🔒 **Saut à hauteur variable** : tap court = petit saut · doigt MAINTENU pendant la MONTÉE = gravité ÷2 (grand saut). Le relâchement n'affecte jamais la descente (retombée toujours à gravité normale).
- 🔒 **Ptérodactyle = anti-impulsivité** : niveau 2+ (`G.level >= 2`), il vole bas et NE FAUT PAS sauter dessus (sauter dessus = trébuchement comme un cactus raté).
- 🔒 **Collision indulgente** : boîtes AABB réduites à 70% avant test de recouvrement.
- 🔒 **Trébucher ≠ fin de partie** : jamais de « game over », jamais de mot punitif. Rex trébuche (petit clignotement + « 😅 »), courte pause, la course CONTINUE automatiquement.
- 🔒 **Vitesse initiale LENTE, accélération douce PLAFONNÉE** (`SPEED_CAP`) — refus du chrono-stress (décision PY). Le palier d'accélération se déclenche à la fin de chaque segment, jamais en cours de segment.
- 🔒 **Distance = jalons ILLUSTRÉS** (🌿 Fougère → 🪨 Rocher → 🌋 Volcan → ⛰️ Sommet) — **zéro chiffre de score/distance affiché**.
- 🔒 **1 partie = 4 segments fixes** (`TOTAL_SEGMENTS = 4`), indépendant du niveau golden (le niveau pilote uniquement la difficulté des obstacles, pas le nombre de segments). `attempts` par segment : **1** si aucun trébuchement dans le segment, **2** sinon → `G.notePip(segIndex, attempts)`.
- 🔒 **Niveaux (`G.level` 0/1/2)** : N1 = cactus simples seuls, lent · N2 = + cactus doubles (grand saut) + œufs bonus en arc · N3 = + ptérodactyle, densité un peu plus forte (toujours plafonnée par `SPEED_CAP`).
- 🔒 **Entrée** : `pointerdown`/`pointerup` sur TOUT le canvas — aucun bouton à viser.
- 🔒 **Pause propre** quand l'onglet est caché (`visibilitychange`), reprise sans saut fantôme au retour.
- 🔒 Fin du 4e segment → `shell.G.showEnd` (gabarit standard, célébrations MaxFX bibliothèque uniquement).
- 🔒 Jamais le prénom Max dans le contenu du jeu.
