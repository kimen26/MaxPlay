# Prénoms — Austronésien (javanais, balinais)

> Aire : Indonésie — Java (javanais), Bali (balinais). Tradition hindo-bouddhiste à Bali, syncrétisme musulman-animiste à Java.
> Particularité : sonorités très douces, voyelles ouvertes, prénoms à **signification poétique forte** (lumière, paix, eau sacrée, essence). Mythologie douce, accessibilité enfants élevée.

---

## Bahagia

**Genre** : mixte
**Origine** : Javanais / indonésien — *bahagia* ("bonheur, félicité")
**Signification** : "joie, félicité"
**Sonorité** : doux · 4 syllabes (ba-ha-gi-a) · ressenti ample, lumineux
**Usage** : vivant
**Ennéatypes possibles** :
- **Type 7 — Épicurien** : *"joie, félicité — sens direct"* (alignement fort)

**Statut** : brouillon
