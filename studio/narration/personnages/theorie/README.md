# Théorie sur l'humain — Index

> **Sous-pilier de [`personnages/`](../INDEX.md).** Théorie applicable à l'écriture MaxPlay, deux faces :
> - Comprendre **les personnages** (ennéagramme) — qui ils sont, comment ils réagissent, comment ils interagissent
> - Comprendre **le lecteur** (pédagogie 4-5 ans) — comment Max et ses pairs perçoivent une histoire à cet âge
>
> Les deux sont des **invariants** (théorie sur l'humain), pas variables par culture.

## Usage dans le workflow d'écriture

Ces deux dossiers sont des **ressources obligatoires** à consulter à 3 moments :

| Moment | Quoi consulter |
|--------|----------------|
| **Brainstorm** (idée d'histoire) | `pedagogie-enfance/` pour calibrer cognition 4-5 ans + `enneagramme/chabreuil-synthese-complete.md` §8.3 (comportements 4-7 par type) |
| **Plan** (Kishōtenketsu) | `enneagramme/guide-auteur.md` + `interactions-9x9.md` si plusieurs persos |
| **Briefs writers** | `enneagramme/` pour identifier les comportements à diluer + `pedagogie-enfance/` pour le tempo/vocabulaire |

→ Le [`equipe/PROCESS.md`](../../equipe/PROCESS.md) impose cette lecture en étapes 1-3 (Pitch / Plan / Briefs).
