## Ce que je retiens le plus

1. **Le moment où la main de Wex entre dans la tache avec l'ombre** — ça c'est magique. Quand il lève la main dans la lumière et ZAP son ombre glisse jusqu'à la grande tache noire et entre dedans. C'est LE moment.
2. **Les trois ombres qui dansent ensemble** — l'oiseau qui bat des ailes, le loup qui ouvre la gueule, et la main qui bouge. Tous ensemble. C'est comme un jeu où on gagne tous les trois, pas juste Raph qui saute toute seule.

## Ce qui m'a perdu ou ennuyé

- **Trop de description dans claude-opus-def et kimi-k26-thinking** — "Elle pencha la tête", "Une fourmi traversait", "L'air sentait" — je capte pas ces trucs quand je suis petit. Je veux juste voir le mouvement.
- **Les mots bizarres** — "trou de soleil", "pétale", "une feuille sèche" — à 4 ans j'ai pas la tête pour les poésies. C'est joli pour papa/maman mais moi je veux comprendre VITE.
- **Les fins molles** — dans grok-def, deepseek-def : le nuage passe, les ombres disparaissent, c'est tout. Pas de "Elle reviendra" pour me dire qu'on peut recommencer. C'est triste.
- **Raph qui saute seulement vs. Raph+Madie+Wex ensemble** — dans les versions où Raph sautille toute seule longtemps, je m'ennuie. Y'a pas de surprises. Les meilleures versions c'est où les trois font des ombres ensemble.
- **"Elle bouge pas pareil" répété trop** — dans grok-reco on l'entend plusieurs fois, ça lasse.
